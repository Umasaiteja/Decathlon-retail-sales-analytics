# Decathlon-retail-sales-analytics
Self-initiated Excel analytics project based on a DataCliQ tutorial. Used Excel and Power Query to explore a synthetic 30,000-record retail dataset, analyze sales, customer, product, and time-based trends, calculate KPIs, and present findings in an Insights sheet and dashboard.

The workbook demonstrates an Excel and Power Query workflow for preparing and exploring retail sales data. It includes source data, analysis sheets, an Insights sheet, and a Dashboard with PivotTables and charts.
The analysis is organized around:
Sales performance and time-based trends
Orders, customers, and average order value (AOV)
Product, category, and sport-type performance
Customer segments, gender, and retention

## Workbook

Open link https://github.com/Umasaiteja/Decathlon-retail-sales-analytics/blob/main/Decathlon_RetailAnalytics_Data_30000.xlsx in Microsoft Excel (Download Recommended) for the full analysis and dashboard. The source workbook contains 30,000 data records and five worksheets, including `Insights` and `Dashboard`.
